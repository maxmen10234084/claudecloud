# Digitaler Vorlagen-Shop

Eine einfache Verkaufsseite für digitale Produkte wie Vorlagen, Planer oder E-Books.
Sie kostet dich nichts im Betrieb und funktioniert **ohne Programmierkenntnisse**.

- **Hosting:** kostenlos über GitHub Pages
- **Zahlung:** Gumroad oder Lemon Squeezy (übernehmen auch EU-Umsatzsteuer und Rechnungen)
- **Bearbeiten:** Du änderst nur eine Datei, nämlich `config.js`

👉 **Starte hier: [ANLEITUNG.md](ANLEITUNG.md)**

## Dateien

| Datei | Zweck | Bearbeiten? |
|---|---|---|
| `config.js` | Shopname, Texte, Produkte, Preise, Kauf-Links, FAQ | **Ja** |
| `impressum.html` | Impressum (Pflicht in Deutschland) | **Ja**, einmalig die markierten Stellen |
| `datenschutz.html` | Datenschutzerklärung | **Ja**, einmalig die markierten Stellen |
| `index.html`, `assets/` | Aufbau und Design der Seite | Nein |
| `.github/workflows/pages.yml` | Veröffentlicht die Seite automatisch | Nein |

## Lokal ansehen

Doppelklick auf `index.html`, dann öffnet sich die Seite im Browser.
